## [1.2.1] - 2026-11-25

### Security

- 媒体代理只允许访问公网地址：内网、回环、链路本地与云厂商元数据地址一律拒绝，重定向后的目标同样校验。
- MCP 出向连接收紧：SSE 服务器下发的提交端点、HTTP 重定向、OAuth 发现链与授权服务器端点都必须同源或公网，不再无条件采信对端给出的地址。
- 出向 MCP 的长期令牌只在生成时完整显示一次，服务端只保存哈希；已配置的旧令牌在升级后自动迁移，现有客户端无需重新配置。
- MCP OAuth 回调页对错误参数做转义，第三方构造的链接不能再把标记注入页面当脚本执行。
- pprof 调试端点默认只监听本机，需要对外时必须显式开启。
- 数据目录与数据库文件权限收紧为 0700 / 0600，同机其他用户不再能读到订阅与令牌。

### Fixed

- 刷新不再把标题、站点地址等你在界面上改过的字段覆盖回订阅源给的值。
- 订阅地址改动后，旧地址仍在途的响应不会再写进新订阅；改地址时同时清掉旧的 ETag 与 Last-Modified，新地址不会被误判成未更新而跳过。
- RSS 条目写入失败时不再推进缓存校验值，下次刷新会补齐漏掉的条目，不会永久缺条。
- 解压后超过 8 MiB 的订阅响应被拒绝：预览返回 502 且不会建出空订阅，刷新保留原有条目并记录失败原因。
- 首次注册并发只允许一个成功，另一个得到「用户已存在」；改密时密码与新令牌密钥一起写入，失败不会留下半初始化的账号或仍然可用的旧令牌。
- 刷新被拒（已有刷新在跑）不再把触发来源从「定时」改写成「手动」。
- 刷新部分失败不再报成功：手动刷新返回失败，定时任务记为部分失败，日志与结果列表都能看出是哪几个源失败、哪几个被跳过。
- 内容没有变化的条目不再重复写库，每轮刷新不再无谓重写整张表。
- 刷新不再因为站点没有图标而白等十几秒：单轮耗时从约 11 秒降到约 3 秒。
- 删掉从未被查询使用的全文索引，库体积与写入开销一并下降。

### Changed

- 正文渲染与语言检测改为按需加载：首屏体积减少约 78 KB（gzip），打开第一篇文章不再预加载语言检测的 447 KB。
- 界面可访问名称改为跟随语言设置（返回顶部、订阅列表、查看大图、播放视频），英文界面下不再出现中文读屏文案。
- 插件文档写清信任模型：安装插件等于让它在本机执行代码，并列出可用的部署隔离做法。

## [1.2.0] - 2026-11-23

### Added

- 设置中心整体重设计：订阅、文件夹、通用、插件、自动化、网络、高级、关于，以及「数据控制」「AI」页统一为分区卡片与行式控件，层级更清晰、窄屏更整齐。
- AI 提供商支持一个提供商下挂多个模型：新建或编辑时可自动探测模型、一键全部加入并选择默认模型；翻译、摘要等不同场景可分别指定具体模型。
- 移动端列表条目支持左滑快捷操作：左滑露出「已读/未读切换」和「星标」，点一下即可完成，不必再长按打开菜单。

### Changed

- 自动化规则的条件默认改为「或」组合：任一条件满足即命中。
- AI 提供商切换「当前使用」时会一并保留该提供商已填的 API Key，不再丢失；AI 行为设置未保存时离开会提示，可选择「保存并离开」。
- 设置页控件统一：提供商卡片的协议名本地化，分场景未选择时显示「跟随当前使用」，无描述的卡片标题与图标垂直居中，输入框恢复统一圆角与焦点环，窄屏操作区可换行。

### Fixed

- 在「只看未读」列表里手动标已读（右键菜单、悬停操作、快捷键、移动端操作面板、左滑动作）后，条目不再当场消失：只变灰留在原位，离开列表时才按未读规则移除。
- 兼容忽略 `stream:false`、仍返回流式（SSE）响应的 AI 提供商，连通性测试与翻译不再报错。
- 修复模型翻译偶发整段未翻译的问题（短文本、占位符不再被误判为已译），并修正正文页摘要/翻译的状态显示。
- 摘要缓存恢复时带回原模型来源，顶栏悬浮可显示实际使用的模型。
- 修复星标未读筛选、切换视图后已读残留的问题。
